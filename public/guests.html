    Edge regions

    The Telnyx Portal shows which Edge regions served the function (Edge Compute → this function → regions), as a share of its requests. Telnyx doesn't offer that split through its API yet, so it isn't shown here. Read it like the chart above: requests, not guests. Each request is served by the region nearest the caller, and a single long session or an automated checker can tip the split. For where guests are, see the Where tab.
